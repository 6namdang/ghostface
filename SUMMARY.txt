📱 WHAT WAS BUILT
--------------------------------------------------------------------------------

A complete Progressive Web App for face recognition assistance, designed to 
help people with prosopagnosia (face blindness) recognize the people in their 
lives.

KEY FEATURES:
✅ Real-time face recognition using camera
✅ Easy enrollment (add people with 3-20 photos)
✅ Gallery management (view, edit, delete)
✅ Text-to-speech audio feedback
✅ Privacy-first (all data stored locally)
✅ Offline capable (after first load)
✅ Installable on iOS and Android
✅ Native-like experience

TECHNOLOGY:
- Frontend: Vanilla JavaScript (no framework)
- Face Recognition: @vladmandic/face-api (ArcFace via TensorFlow.js)
- Storage: IndexedDB (browser local storage)
- PWA: Service Worker + Web App Manifest
- Models: TinyFaceDetector + FaceLandmark68 + FaceRecognition

🚀 HOW TO RUN
--------------------------------------------------------------------------------

OPTION 1 - Python (Recommended for Desktop):
  $ cd /projects/sandbox/ghostface
  $ python3 -m http.server 8000
  Then open: http://localhost:8000

OPTION 2 - Quick Start Script:
  $ cd /projects/sandbox/ghostface
  $ ./start.sh

OPTION 3 - Node.js:
  $ cd /projects/sandbox/ghostface
  $ npx http-server -p 3000

--------------------------------------------------------------------------------
📱 MOBILE DEPLOYMENT (Required for Camera)
--------------------------------------------------------------------------------

Camera access requires HTTPS on mobile devices!

FASTEST METHOD - Netlify Drop:
  1. Go to https://app.netlify.com/drop
  2. Drag the entire "ghostface" folder
  3. Get instant HTTPS URL (e.g., https://random-name.netlify.app)
  4. Open on your phone and "Add to Home Screen"

ALTERNATIVE - ngrok (For Testing):
  $ python3 -m http.server 8000  # In one terminal
  $ ngrok http 8000              # In another terminal
  Then open the HTTPS URL on your phone!

OTHER OPTIONS:
  - Vercel: Run `vercel` in the project directory
  - GitHub Pages: Push to GitHub and enable Pages
  - Firebase: Run `firebase deploy`
  - Surge: Run `surge` in the project directory

See DEPLOYMENT.md for detailed instructions for each platform.

--------------------------------------------------------------------------------
🎯 HOW TO USE
--------------------------------------------------------------------------------

ADDING PEOPLE:
  1. Tap "Add Person" tab
  2. Enter the person's name
  3. Capture 5-10 photos (different angles/lighting)
  4. Tap "Save Person"

RECOGNIZING FACES:
  1. Tap "Recognize" tab
  2. Tap "Start Camera" button
  3. Point camera at a face
  4. See the name displayed in real-time!
  5. Toggle audio on/off with "Audio" button

MANAGING GALLERY:
  1. Tap "Gallery" tab
  2. View all enrolled people
  3. Edit names or delete people as needed

--------------------------------------------------------------------------------
🔒 PRIVACY & SECURITY
--------------------------------------------------------------------------------

✅ All face data stored locally in IndexedDB
✅ No server-side processing
✅ No analytics or tracking
✅ Works offline after first model load
✅ No account required

⚠️ IMPORTANT: Face embeddings are biometric data. Get consent before 
enrolling other people. Some jurisdictions (BIPA in Illinois, GDPR in EU) 
have legal requirements for handling biometric data.

--------------------------------------------------------------------------------
⚙️ CONFIGURATION
--------------------------------------------------------------------------------

RECOGNITION THRESHOLD:
  - Default: 0.6 (conservative)
  - Located in app.js: processDetections()
  - Lower = more strict (fewer false positives)
  - Higher = more lenient (more detections, more errors)

MODELS:
  - Loaded from CDN on first use (~7MB)
  - Cached by Service Worker
  - Change MODEL_URL in app.js to use different models

ICONS:
  - SVG icons included
  - Generate PNG icons using generate-icons.html
  - Or use online converter: cloudconvert.com/svg-to-png
